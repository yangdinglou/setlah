# Process notes (historical)

Working documents from the refactor that replaced the egglog front half with the
direct lowering (August to September 2026). They are kept as a record of why the
code looks the way it does; none of them describes current behaviour, which is
in `docs/architecture.md`, `docs/cli.md` and `docs/language.md`.

- `refactor-brief.md`: the brief for the refactor (what egglog did, the two tracks).
- `refactor-prompt.md`: the prompt the refactor session was started with
  (contains absolute paths of the author's machine).
- `track-a-results.md`: Track A, fixing the egglog front half in place.
- `track-b-results.md`: Track B, the direct lowering, with its measurements.

The proposal to retire egglog, of which step 1 is done, is still current and
stays at `docs/retire-egglog-proposal.md` (the CLI's deprecation warning cites it).
