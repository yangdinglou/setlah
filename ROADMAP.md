# SetLaH Roadmap

The following work is planned beyond the first Lean end-to-end milestone:

- Publish a formal language specification and compatibility policy.
- Add source spans and higher-quality parser and type diagnostics.
- Publish coordinated Python and Lake releases with a compatibility table.
- Add timeouts, cancellation, streaming models, optimization results, and
  solver statistics.
- Design the richer control API required by QCLS and incremental grounding.
- Expand benchmarks with expected SAT/UNSAT outcomes and model properties.
- Add a formatter, syntax highlighting, editor support, and eventually an LSP.
- Add namespace and module support with stronger symbol and type checking.
- Investigate proof-producing or independently checkable solver results for
  Lean applications.
- Add performance regression tests and protocol process reuse if startup cost
  becomes material.
